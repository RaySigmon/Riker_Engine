## Behavioral Changes (release notes)

1. **Phase 5 cross-tissue tolerance now active.** Blood replication failures for brain-discovery diseases no longer trigger elimination. ASD: 35 survived (was 20). This is the correct behavior per the engine's design.

2. **Mean log2FC computation changed.** Downstream consumers (Phase 2 features, Phase 4 permutation, Phase 4 core gene reporting) now use significant-datasets-only average instead of all-datasets average. Both values appear in CSV outputs. This changes clustering behavior and may shift core gene counts by up to ~20%.

3. **RNG implementation changed.** np.random.default_rng replaces np.random.RandomState in permutation.py. Same seed produces different RNG stream. Empirically verified: core gene identification is robust to this change when phase-specific seeds are held constant.

4. **New output files.** phase2_feature_matrix.csv and phase3_cluster_assignments.csv are now written alongside existing outputs.
