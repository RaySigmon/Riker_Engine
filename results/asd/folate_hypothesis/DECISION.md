## DECISION: **PROCEED — Hypothesis paper warranted**

### What this investigation found:

1. **The original MTHFR-specific hypothesis was wrong as framed** — but the data pointed to something better
2. **A dose-dependent UMFA → FRAA → CFD → CDR chain** is supported across molecular, biochemical, computational, transcriptomic, and partially epidemiological evidence
3. **The B12 synergy** (HR 17.6) has a novel mechanistic explanation (peripheral sink) that no one has published
4. **The Riker Engine data contains TWO independent supporting signatures**: metabolic (MAT2B, Cluster 21, 47 mito genes) AND immune (59 genes, 95% upregulated)
5. **Multiple novel, testable predictions** emerge that no existing study has tested

### Recommended Next Steps (Priority Order):

1. **Write reframed hypothesis paper** for Medical Hypotheses or similar
   - Core chain: Excess FA → UMFA → FRAA → CFD → CDR → ASD
   - B12 amplification via peripheral sink
   - Riker Engine supporting data (MAT2B, Cluster 21, immune signature)
   - Novel predictions (R1: UMFA-FRAA correlation, R2: epitope analysis)

2. **Share with Dr. Naviaux** — reframed version with full evidence
   - MAT2B + ENTPD6 + TXNIP + C1q connect directly to CDR
   - The immune signature (59 genes) independently validates the autoimmune-CDR intersection
   - Ask about Frye collaboration for leucovorin MTHFR reanalysis

3. **Highest-value experiment to propose**: Measure UMFA levels AND FRAA titers in the same cohort. This has never been done. It would definitively test the hinge prediction.
